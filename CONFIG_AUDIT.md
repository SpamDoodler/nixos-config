## Open issues: efficiency and maintainability

- **Mutable script deployment:** compositor bindings run `$HOME/nixos/scripts`.
  Package with `writeShellApplication` and explicit runtime inputs, but recognize
  that losing live-edit behavior is a deployment change. Keep pictures/state mutable.
- **Process ownership:** Hyprpaper is launched manually while its service is
  disabled; Fcitx has compositor startup plus system integration. Determine actual
  owners before enabling/removing services. Waybar toggles kill by process name
  globally, potentially affecting another session.
- **Neovim:** Treesitter setup is duplicated and disagrees about highlighting;
  Nix grammars/LSP tooling coexist with mutable installer tooling. Consolidate only
  after verifying effective plugin behavior, not merely absence of explicit setup.
- **Shell prompt:** Oh My Zsh `agnoster` and Starship both configured; verify final
  initialization order before choosing one owner.
- **Resource tuning:** `system/nix.nix` has eight concurrent jobs with effective
  `cores = 0`, a large download buffer, and ccache sandbox exposure without clear
  compiler integration. `system/systemd.nix` raises global limits. Document measured
  reasons before changing limits or claiming ccache acceleration.
- **Insecure allowance:** determine whether `electron-24.8.6` is still consumed
  before removing its exception or changing an application.
- **Dormant settings:** resolved and Hyprpaper disabled blocks, and relay-oriented
  Tor settings, may document intent rather than apply policy. Do not enable them
  as cleanup. Same caution applies to explicit disabled power services.
- **Package ownership:** system/Home Manager overlaps do not duplicate store bytes.
  Preserve system-wide availability and user wrappers when consolidating.
- **Fonts/graphics:** review non-font `pango`, BrownPro source formats, and graphics
  tools in driver packages separately. Preserve installed font bytes and matches.
- **SSH/firewall:** password SSH is enabled; root uses `prohibit-password`.
  Effective TCP ports are 22, 27015, 27036, 27037; UDP ports are 5353, 10400,
  10401, 27015, 27036 plus 27031–27035. Inventory all module contributions before
  changing exposure. Source `allowedTCPPorts` alone is not the full policy.
- **OpenCode maintenance:** scratch sessions have no expiry; launcher parsing tracks
  upstream CLI semantics manually. Add bounded parser tests/retention documentation
  before changing behavior. Prompt-only read-only constraints are not permissions.

## Verification protocol

Use locked offline evaluation of `NixSama`, not an unrelated standalone module.
Compare against the baseline Git revision: assertions, generated file contents,
package identities/order (deduplicated only where explicitly intended), services,
firewall, groups, kernel parameters, fonts and application options. Check the
preserved legacy Hyprland module and lockfile have no diff.

Run the repository Alejandra formatter on changed Nix files only, and `git diff
--check`. Build affected outputs when needed, without activation. Derivation
identity can change from comments/source inputs alone; investigate differences
rather than equating hash equality with full runtime equivalence. Subsequent
lifecycle changes require live fresh-login and reload checks.
