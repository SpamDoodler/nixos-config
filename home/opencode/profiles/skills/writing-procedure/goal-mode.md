# Writing under /goal


The /goal reviewer is this session's own model and reads the whole history. A round stalls if you made no tool calls, or if the same reason repeats. So: end your turn while subagents run (their reports wake you); make each round change the draft or the plan; write one status line per round: `ROUND n | phase | reader: match/mismatch | fidelity issues k | stylecheck verdict | next: <what>`. Done only when the FINAL CHECK block passes.
