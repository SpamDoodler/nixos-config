# Research planning kit

Supporting files in this skill's directory. Read the one you need when you need it, not all at once:

| File | Read when |
| --- | --- |
| `framing-template.md` | Writing or editing `research/FRAMING.md` (phase 0) |
| `plan-template.md` | Writing `research/PLAN.md` |
| `task-card.md` | Before writing the first card of a session, and its checklist before each launch batch |
| `claims-template.md` | Creating `research/CLAIMS.md` |
| `difficulty-rubric.md` | Grading tasks; re-read when `bench report` shows miscalibration |
| `decomposition.md` | Before building the first task graph, and whenever `ledger stats` shows low parallelism |
